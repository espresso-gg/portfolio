# Uzair — Lunar Portfolio

A cinematic creative-developer portfolio built around a lunar-gothic visual
system, smoked acrylic surfaces, restrained motion, and an interactive eclipse.

## Development

```bash
npm install
npm run dev
```

The production deployment is built with Vinext for Cloudflare Workers:

```bash
npm run build
```

## Stack

- Next.js and React
- Motion
- Lenis
- Three.js, React Three Fiber, and Drei
- Vinext and Cloudflare Workers
